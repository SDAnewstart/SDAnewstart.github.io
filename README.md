# ISBHS (국제성경건강학회) — GitHub Pages

비용 없는 정적 웹(학회 레터/소식/행사/자료) 운영을 위한 최소 구성입니다.

## 게시 방법
1) Settings > Pages > Deploy from a branch — Branch: `main`, Folder: `/ (root)`
2) (선택) 커스텀 도메인 연결: `CNAME` 파일 생성 후 DNS 설정
3) 새 글은 `news/_posts/yyyy-mm-dd-title.md` 또는 `letters/yyyy-mm-dd-id.md`로 추가

## 폴더
- `/letters` : 학회 레터
- `/news`    : 공지·블로그
- `/events`  : 행사 안내
- `/resources`: 표준/가이드/정책
